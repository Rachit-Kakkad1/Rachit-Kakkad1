> ### 🧠 `COS` — Cognitive Operating System &nbsp;&nbsp; ![FOUNDER](https://img.shields.io/badge/FOUNDER-64ffda?style=flat-square&labelColor=0a192f)
>
> **The personal AI OS that thinks, remembers, and acts on your behalf.**
>
> COS is not just another chatbot wrapper. It's a modular, agentic operating layer that sits between you and your digital environment — replacing context-switching friction with a unified cognitive interface. Persistent cross-session memory, tool orchestration, OS-level control, and extensible plugin architecture.
>
> ```
> Architecture  Perception Layer → Memory Engine → Reasoning Core → Action Dispatcher
> Memory        Episodic + Semantic + Procedural (vector-backed long-term store)
> Tools         File I/O · Web Reasoning · Calendar · Code Execution · API calls
> Interface     Voice (Whisper) + Text + Programmatic
> ```

> ### 🤖 `Jarvis` — Offline AI Voice Assistant &nbsp;&nbsp; ![IN PROGRESS](https://img.shields.io/badge/IN%20PROGRESS-f59e0b?style=flat-square&labelColor=0a192f)
>
> **A locally-run, privacy-first voice + text AI assistant. No cloud. No API leaks. Full control.**
>
> Offline-first, extensible, and genuinely autonomous. Whisper handles voice transcription, pyttsx3/ElevenLabs drives synthesis, and a Python agent layer handles tool dispatch, memory retrieval, and task orchestration. Built in phases: voice I/O → memory → OS control → web reasoning → full agent loop.
>
> ```
> Phase 1   Voice I/O — Whisper STT + pyttsx3 TTS                    ✓ Done
> Phase 2   Memory layer — session + persistent context               ✓ Done
> Phase 3   OS control — file system, app launch, window mgmt        🔧 Active
> Phase 4   Web reasoning — live search + page summarization          ⬜ Next
> Phase 5   Full agent loop — autonomous task planning + execution    ⬜ Next
> ```

## 🧭 &nbsp; Engineering Philosophy

<br/>

<div align="center">

> ### *"Ship fast. Think deep. Build things that last."*

</div>

<br/>

```
  The principles I build by:

  ① DEPTH OVER SURFACE
    Don't just make it work. Understand why it works.
    Every system I build starts with: "What is this actually doing?"

  ② RELIABILITY IS THE PRODUCT
    Intelligence without reliability is a demo, not a product.
    If users can't trust it, it doesn't matter how smart it is.

  ③ SHIP → LEARN → ITERATE
    Perfect is the enemy of shipped. Build the MVP, get real feedback,
    then compound improvements from real-world usage.

  ④ SYSTEMS THINKING
    Every component exists in relation to others. Optimize the system,
    not the component. Local maxima are traps.

  ⑤ BUILDER'S IDENTITY
    I don't identify with a tech stack. I identify with solving problems.
    The tools are means. The outcome is the measure.
```

<br/>

<div align="center">

| 🔬 Depth | ⚡ Velocity | 🛡️ Reliability | 🔭 Observability | 📐 Systems |
|:---:|:---:|:---:|:---:|:---:|
| Go beyond surface | Speed is a feature | Trust is non-negotiable | Know what's happening | Optimize the whole |
